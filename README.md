# App de Receitas Financeiras

Aplicação simples para controle de receitas financeiras.

## Tecnologias

### Backend
- Java 24
- Spring Boot
- Spring Data JPA
- PostgreSQL
- Maven

### Frontend
- React
- Vite
- JavaScript

### Banco de dados
- PostgreSQL
- pgAdmin

---
